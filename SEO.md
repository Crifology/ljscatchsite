# Search visibility for LJ's Catch

## What is implemented

- Unique titles and descriptions on all six public pages, focused on each page's actual content.
- Open Graph sharing titles and descriptions, with a logo image in production.
- Canonical URLs using https://www.ljscatch.com and basic WebSite structured data on the homepage.
- A six-page sitemap at `/sitemap.xml` and `/robots.txt`, generated by `npm run build`.
- Netlify deploy previews and branch deploys receive `noindex` tags.
- Visible homepage copy describes family fishing and outdoor recreation.

`seo.json` records the public domain and sitemap pages. If you add a page, give
it a unique title and description in its source HTML and add its entry here.
Keep the source metadata and config descriptions consistent. SITE_URL can
override the configured domain. SEO output is in `dist`; deploy through the
Netlify build so canonical tags and the sitemap are included.

## After deployment

1. Verify the domain in Google Search Console (requires the site owner's account
   and DNS access). Submit https://www.ljscatch.com/sitemap.xml.
2. Inspect the homepage and tracker URL in Search Console and request indexing.
   Confirm Google can fetch the rendered pages and their assets.
3. Ensure the Netlify primary domain is `www.ljscatch.com`, with HTTPS and domain
   aliases redirected there. Check that sitemap URLs resolve successfully.
4. Monitor search queries, impressions and clicks over time. Use those queries
   to improve the pages visitors already find useful.
5. Check mobile performance with PageSpeed Insights. Large gallery photos are
   candidates for appropriately sized WebP/AVIF copies; retain originals.

## Content to prioritize

Start with first-hand, specific pages rather than trying to rank for the single
word "fishing":

- A family's first fishing trip: what you actually brought and what worked.
- Fishing for sunfish with kids: LJ's experience, photos, and lessons learned.
- Lake-day stories with accurate location context and original catch photos.
- How to use the fish tracker, including the limits of historical fish records.

Use descriptive headings and internal links from relevant existing pages.
Identify authors and distinguish personal experience from sourced advice.
Verify current access rules and fishing regulations with the relevant state
agency before publishing location advice. Do not present historical tracker
records as guaranteed catches or publicly accessible fishing spots.

No keyword meta tags, invented reviews, business locations or ranking guarantees
are included. Metadata helps search engines understand pages; it does not
replace useful content or guarantee indexing or rankings.
